# Do privacy regulations apply?

**Why it matters** A genuinely public app storing per-person progress and setting a long-lived
identifier raises consent, erasure and privacy-policy questions. Nothing in this project has
ever examined them. Also unexamined: age gating, data residency for any backup, and payment
obligations if a paid tier appears.

**Gates** [are there user accounts](are-there-user-accounts.md),
[is there a paid tier](is-there-a-paid-tier.md).

**Resolves into** `constraints.md`.
