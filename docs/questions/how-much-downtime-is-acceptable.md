# How much downtime is acceptable?

**Why it matters** A single machine has no hardware redundancy, and backups protect data, not
availability. Accepting that is entirely reasonable for a project this size — but it should be
accepted explicitly, with a tolerable outage length attached, rather than discovered during
one.
