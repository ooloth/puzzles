# Is home-screen install required for durability?

**Why it matters** Install is the only confirmed exemption from Safari's seven-day wipe of
script-writable storage. Requiring it puts friction on an audience assumed to have no
technical sophistication. Not requiring it means the durability guarantee is materially
weaker for most players than for some — and we would be promising something we only
sometimes deliver.

**Gates** onboarding design, the wording of the durability guarantee.

**Settled by** [how much unsynced work is acceptable](how-much-unsynced-work-is-acceptable.md)
— a tight enough sync cadence makes install unnecessary. Also informed by
[what resets Safari's seven-day clock](what-resets-safaris-seven-day-storage-clock.md).
