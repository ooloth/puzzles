# Is there a paid tier?

**Why it matters** It changes the stakes. "Nothing is ranked or money-involved, so anti-cheat
isn't a design driver" stops being true the moment something is worth gating.

**Gates** anti-cheat posture, [are there user accounts](are-there-user-accounts.md), payment
and tax obligations.
