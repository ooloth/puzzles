# Does craft enjoyment ever outrank user experience?

**Why it matters** Enjoying the build is a legitimate and stated motive for this project. It's
also the kind of motive that quietly justifies technical choices on other grounds. Better
answered openly, once, than smuggled into individual decisions as a performance or
architecture argument.

**Gates** [what runs the server and in what language](what-runs-the-server-and-in-what-language.md),
and any future decision where the enjoyable option and the better option differ.
