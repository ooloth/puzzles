# What resets Safari's seven-day storage clock?

**Why it matters** The documented rule is seven days without "user interaction with the site",
which is not defined. Whether any interaction counts, or only a top-level navigation, decides
whether a regular player is ever actually at risk — and therefore how much design effort the
whole eviction problem deserves.

**Would be settled by** WebKit documentation and a real-device test.
